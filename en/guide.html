How to install Renegade

Five minutes from download to playing. If something goes wrong, check “Problems” at the bottom.

1. Download2. Windows warning3. Install 4. First launch5. PlayFiles & configsUninstallProblems
1

Download the installer

Press the button to download Renegade-Setup.exe. You need Windows 10 or 11 (64-bit).

Download

Free · Windows 10/11

Only download from this site or our Discord. Copies on other sites may be tampered with.

2

If Windows shows a warning

The installer is not signed with a paid certificate yet, so SmartScreen may show a blue “Windows protected your PC” window. It does not mean a virus was found — Windows simply doesn't “know” the file yet.

  1. Click the “More info”.
  2. A “Run anyway” button appears — click it.

3

Install

The installer window opens (it is in Russian for now). Keep the folder as is, shortcuts are up to you. Press “Установить” (Install) — in about half a minute a “Запустить” (Launch) button appears.

No admin rights needed. If Renegade is already installed, the button reads “Обновить” (Update) — settings and worlds are kept.

4

First launch

On the very first start the launcher downloads Java (about 95 MB) — only once. If the connection drops, press “Retry”: nothing downloaded so far is lost.

Then, when you press “PLAY”, the launcher downloads Minecraft 1.21.11, Fabric and the client by itself.

5

Play

Press “PLAY”. Once the game is open, the client menu opens with Right Shift . Accounts, themes, the HUD editor and configs live there too. Switch the launcher to English with the RU/EN toggle at the top.

★

Where files live and how to share a config

%APPDATA%\.renegadegame, worlds, screenshots, mods
%APPDATA%\.renegade\config\renegadeclient configs and accounts
%LOCALAPPDATA%\Programs\Renegadethe launcher itself

To open a folder, paste the path into File Explorer's address bar or press Win+R. The folder button on the left of the launcher opens the game folder.

Sharing a config: in the client menu → Configs → “To file”. A .renegade file appears on your desktop — send it to a friend. They double-click it and the config shows up in their game.

Your own mods (Sodium, Iris and others for 1.21.11) go into the mods folder — the launcher's Mods tab has a “Mods folder” button.

✕

Uninstall

Windows Settings → Apps → Renegade → Uninstall. The Renegade uninstall window opens. The game, worlds, configs and accounts (the .renegadefolder) stay — you can delete them by hand.

?

Problems

  • Antivirus deleted a file or blocks the launch. Add the Renegade folder to your antivirus exclusions and download the installer again.
  • The installer window does not respond. Open Task Manager (Ctrl+Shift+Esc), end every “Renegade” process and run the installer again. The install log is %TEMP%\renegade-setup.log.
  • “Could not download Java”. Check your internet and VPN, then press “Retry”.
  • The game crashed. The launcher shows a window with the cause and the suspected mod. Press “Send logs” — the launcher collects them and opens our Discord.
  • Anything else — write to our Discord.
