Launcher

One click and you're in

The launcher downloads Minecraft, Fabric and the client, verifies files and updates itself.

  • Resumable, verified downloads — connection dropped? The download continues where it stopped.
  • Auto-updates for the client and the launcher itself, with a changelog.
  • Crash report — shows what went wrong and which mod is to blame.
  • Discord status — play time and your UID.
Install

Its own installer

No stock Windows wizards and no admin rights. The game, worlds and settings are stored separately — nothing is lost on update or uninstall.

Getting started

Three steps

Download

Press “Download” to get Renegade-Setup.exe.

Install

Run it, pick a folder and press “Установить” (Install).

Play

Press “PLAY” in the launcher. The client menu opens with Right Shift.

FAQ

Frequently asked questions

Is it free?

Yes. Downloading and playing is free.

What do I need?

Windows 10 or 11 (64-bit). No need to install Java — the launcher downloads it on first start (about 95 MB, once). Accounts are chosen in the client menu.

My antivirus complains about the installer — what now?

The installer is new and not code-signed yet, so Windows SmartScreen may show a warning: click “More info” → “Run anyway”. Only download it from this site or our Discord.

Where are my settings and worlds?

In %APPDATA%\.renegade. Neither updates nor uninstalling the launcher touch it.

Which mods does it work with?

Tested with Sodium, Iris, Lithium, ViaFabricPlus, Sodium Extra, Voice Chat, Mod Menu and other popular 1.21.11 mods — see the list above.

How do I uninstall it?

Windows Settings → Apps → Renegade → Uninstall. Our uninstall window opens.

Can I get banned on a server?

Many servers forbid third-party clients in their rules. Read the server rules before playing — you are responsible for how you use it.

Found a bug or have an idea?

Write to us on Discord — attach the launcher crash report if there is one.
